# 📱 校园失物招领应用 (Campus Lost & Found)

## 📖 项目简介
一款基于 HarmonyOS (ArkTS/ArkUI) 开发的校园本地化移动应用。旨在解决传统校园失物招领信息分散、匹配效率低的问题，提供便捷的信息发布、浏览与个人管理功能。

## 🛠 技术栈
- 语言：ArkTS
- UI框架：ArkUI（声明式开发）
- 数据存储：@ohos.data.preferences（本地持久化）

## ✨ 核心功能
1. **信息浏览**：首页双Tab切换（失物招领/寻物启事），支持关键词搜索与分类筛选。
2. **信息发布**：支持发布失物/寻物信息，寻物启事可标记“紧急”并置顶展示。
3. **个人中心**：集成“我的发布、我的收藏、浏览记录”三大板块，支持数据增删与清空。
4. **状态管理**：物品状态流转（进行中/已解决），已解决信息自动后置排序。
